# LLM Orchestrator

This service is responsible for managing interactions with multiple Large Language Model (LLM) providers. It provides a unified interface to call different models and is used by the main API application to power the debate engine.

## Installation

This package is designed to be installed in the same environment as the `api` service. From the root of the monorepo, you can install it in editable mode:

```bash
pip install -e apps/orchestrator
```
